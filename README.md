# Quantum Projects with Qiskit

Welcome to my quantum computing project hub! This repository contains hands-on implementations of fundamental quantum algorithms, protocols, and hardware benchmarks using **Qiskit** and **IBM Quantum Runtime**.

The primary focus of these projects is to explore the transition from ideal statevector theory to real-world execution on physical Noisy Intermediate-Scale Quantum (NISQ) processors.

---

## 📁 Repository Projects

* **[Bell State Generator](./Bell-State-Generator/)**  
  Constructs a modular generator for all four maximal entanglement Bell States ($|\Phi^+\rangle, |\Phi^-\rangle, |\Psi^+\rangle, |\Psi^-\rangle$). Compares ideal statevector probability distributions against physical execution on an IBM Quantum Processor (`ibm_fez`) with hardware transpilation.

---

## 🛠️ Tech Stack & Prerequisites

* **Language:** Python 3.14+
* **Framework:** Qiskit v2.4+
* **Runtime Service:** `qiskit-ibm-runtime`
* **Visualization:** Matplotlib, IPython Display
